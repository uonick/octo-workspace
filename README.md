# OctoWorkspace – Бесплатное приложение для фрилансеров

## Для тех, кто работает с клиентами напрямую
Для фрилансеров и небольших студий. Если вы ведёте проекты, выставляете счета и согласуете работу по этапам: это про вас.

- Графические и веб-дизайнеры
- UX/UI-специалисты
- Разработчики на фрилансе
- Копирайтеры и контент-мейкеры
- Маркетологи и SMM
- Небольшие студии 2–5 человек

## Учёт клиентов, времени и счетов

### Возможности:


- **Ведёт несколько клиентов в одном окне** — показывает статус работ, долги и заметки без лишних переходов между приложениями
- **Генерирует счета и акты** — создаёт документы прямо из приложения, без поиска шаблонов в интернете и платных сервисов
- **Считает часы по проектам и клиентам** — привязывает учёт времени к конкретным делам, а не к отдельному таймеру

### Умеет:

- **Хранить данные локально** — работает с локальной базой данных, данные остаются только на вашем компьютере
- **Работать автономно** — функционирует без интернета, когда сеть недоступна или синхронизация не нужна
- **Уведомлять о важном** — напоминает об оплате счетов и дедлайнах

#### А также
* → Данные никуда не утекают
* → Облако для хранения не нужно
* → Проверено Apple (для macOS)
* → Бесплатно навсегда
* → Есть темная тема
